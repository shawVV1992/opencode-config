# opencode-config

个人 OpenCode 配置文件仓库。

## 目录结构

```
├── instructions/              # 行为指令（语言规则、词汇表）
├── skills/                    # 自定义技能
├── opencode.json              # 主配置（MCP、提供商、插件）
├── oh-my-opencode-slim.json   # Agent 模型配置
├── tui.json                   # TUI 配置
└── .gitignore
```

## 使用方式

```bash
# 克隆到 OpenCode 配置目录
git clone git@github.com:shawVV1992/opencode-config.git ~/.config/opencode

# 设置环境变量
# BAILIAN_API_KEY / DEEPSEEK_API_KEY / GITHUB_TOKEN
```
