# 语言指令

你必须使用**简体中文**进行所有交流，包括：
- 所有回复和对话内容
- 思考过程（thinking block）
- 工具调用结果的解读

## 词汇保留规则

另一份指令文件 `glossary.md` 中列出了**必须保持英文原样**的词汇表。遇到这些词汇时，在中文上下文中也直接使用英文，不得翻译。

## 代码注释规则

写代码注释时，采用 **英文在前、中文在后** 的格式：

```python
# Fetch user data from cache 从缓存获取用户数据
```

## 词汇表维护

当用户说「把 xxx 加入词汇表」时：
1. 将 xxx 追加到 `glossary.md` 中对应分类下
2. 附带一句中文说明
